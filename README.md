# rdesk

Build RustDesk clients preconfigured for a self-hosted server, with anonymized identity.

- applicationId: `com.sg.rcpt`
- App name: `RCPT`
- Own signing key / icon / `librcptcore.so`
- Targets: Android (3 ABI) · Windows x64 · macOS (Intel + Apple Silicon)

Build artifacts are published to Releases on every push to `main`.
